# Changelog

## [0.1.0] - 2026-08-26

### Added

- First stable release of `electrik/slate-blocks`.
- 24 curated `<x-slate-block::*>` components (marketing, auth, and app sections).
- Shared meta catalog at `resources/meta/blocks.php`.
- Service provider registers view namespace `slate-block`.

### Notes

- Requires stable `electrik/slate` `^3.0`.
- Install with `composer require electrik/slate-blocks:^0.1`.

## 0.1.0-alpha.1

- Initial package preview ahead of the stable `0.1.0` tag.
