# Changelog

## [0.2.0] - 2026-10-21

### Added

- Six decorative **illustration** blocks for marketing bentos: deploy, billing, invites, kanban, activity, chat.
- Shared `illustration-shell` frame (window chrome + reduced-motion-aware step loop).
- Optional `resources/css/illustrations.css` for marquee, typing dots, and sparkline bars.
- Illustration copy is prop-driven (`jobs`, `people`, `messages`, `events`, `cards`) with sample defaults.

## [0.1.0] - 2026-08-26

### Added

- First stable release of `electrik/slate-blocks`.
- 24 curated `<x-slate-block::*>` components (marketing, auth, and app sections).
- Shared meta catalog at `resources/meta/blocks.php`.
- Service provider registers view namespace `slate-block`.

### Notes

- Requires stable `electrik/slate` `^3.0`.
- Install with `composer require electrik/slate-blocks:^0.1`.

## 0.1.0-alpha.1

- Initial package preview ahead of the stable `0.1.0` tag.
